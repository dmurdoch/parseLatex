# Print methods

Print methods

## Usage

``` r
# S3 method for class 'LaTeX2item'
print(x, ...)

# S3 method for class 'LaTeX2'
print(x, tags = FALSE, ...)
```

## Arguments

- x:

  Object to work on.

- ...:

  Extra parameters to pass to
  [deparseLatex](https://dmurdoch.github.io/parseLatex/reference/deparseLatex.md).

- tags:

  Whether to display LaTeX2 tags.
