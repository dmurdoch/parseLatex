# Coerce to LaTeX2

Coerce to LaTeX2

## Usage

``` r
as_LaTeX2(x)

latex2(...)
```

## Arguments

- x:

  An object to convert to a
  [LaTeX2](https://dmurdoch.github.io/parseLatex/reference/parseLatex_fn.md)
  object.

- ...:

  Objects to concatenate.

## Value

`as_LaTeX2()` converts `x` to a
[LaTeX2](https://dmurdoch.github.io/parseLatex/reference/parseLatex_fn.md)
object.

`latex2()` converts the arguments to
[LaTeX2](https://dmurdoch.github.io/parseLatex/reference/parseLatex_fn.md)
objects and concatenates them into a new
[LaTeX2](https://dmurdoch.github.io/parseLatex/reference/parseLatex_fn.md)
object.
